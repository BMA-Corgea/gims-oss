Uploads Disabled in Hosted Mode

Uploading executable Python code to a hosted server works only until the environment refreshes — the files live on an ephemeral filesystem that can be replaced at any time. When Elastic Beanstalk or RDS cycles the instance, those uploaded scripts disappear. This restriction prevents users from relying on unstable, short-lived code deployments and protects the system from unverified execution.
